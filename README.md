# Java Calculator

A console-based calculator application built using Java and Object-Oriented Programming.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Square Root
- Power
- Modulus
- Percentage
- Input Validation
- Calculation History
- Reuse Previous Result

## Technologies Used

- Java
- OOP
- ArrayList
- Exception Handling
- Scanner

## Project Structure

src/
├── App.java
├── Calculator.java
└── History.java

## How to Run

1. Compile the project.
2. Run App.java.
3. Choose an option from the menu.
